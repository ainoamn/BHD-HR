### تفصيل آخر جلسة (§49، 16:25)

1. **مرفق وزارة العمل:** عند الحفظ من ملف الوزارة يُنشأ لكل عامل مستند «مرفق بيانات وزارة العمل» يحمل الملف (`attachLabourFile` في `src/lib/employee-intake.ts`)، وتصريح العمل يبقى مستنداً مستقلاً برقمه وانتهائه بلا ملف. الموظف المسجّل مسبقاً يُرفق به الملف دون تغيير بياناته (أو مع تحديثها بخيار). الملف المشترك بين عدة عمال لا يُحذف إلا مع آخر مستند يشير إليه (`removeDocumentFileIfUnused` في `src/lib/uploads.ts`).
2. **إدارة المنصة:** إطار جديد (`src/components/admin/admin-shell.tsx`) ومكوّنات (`admin-ui.tsx`: رسم الأعمدة، الأشرطة، شرائح التصفية، الصفحات، القوائم)، ودوال البيانات في `src/lib/admin-data.ts`. صفحات: النظرة العامة، الشركات (+ تصدير CSV `companies/export`)، صفحة الشركة، المدفوعات، الباقات، المستخدمون، السجل، الإعدادات، والبحث `/admin/search`. الإجراءات في `src/server/admin-actions.ts` بلا تغيير.
3. **الدخول من النطاق المخصص:** `signInOrigin` في `src/lib/request-origin.ts`؛ `start` و`callback` و`admin-entry` تكمل على النطاق الذي بدأ منه الدخول. فُحص على الإنتاج: كل نطاق يرسل `redirect_uri` على نفسه.

## 3. تجهيز الجهاز الآخر

1. **الأدوات:** Node 24 (استُخدم `v24.14.0`)، Git، واختيارياً `vercel` و`neonctl` (`neon`) CLI، وMicrosoft Edge لاختبارات المتصفح.
2. **النسخ:**
   ```powershell
   git clone https://github.com/ainoamn/BHD-HR.git C:\dev\SALARY
   cd C:\dev\SALARY
   npm ci
   ```
3. **ملفات البيئة (غير موجودة في GitHub عمداً):** انسخ القيم من مدير كلمات المرور أو من Vercel/Neon مباشرة — لا ترسلها عبر Git أو البريد.

   | الملف | المتغيرات | المصدر |
   |---|---|---|
   | `.env.local` | `DATABASE_URL`، `DATABASE_URL_UNPOOLED`، `NEON_BRANCH` | `neon link` على مشروع BHD HR (يكتبها تلقائياً) أو لوحة Neon |
   | `.env.local` | `BACKUP_KEY` | مدير كلمات المرور فقط (لازم لفتح النسخ الاحتياطية ولإعادة نشر دالة النسخ). **بدونه لا تُفتح أي نسخة** |
   | `.env` | `AUTH_SECRET` (قيمة محلية عشوائية، ليست قيمة الإنتاج)، `APP_ORIGIN=http://localhost:3000`، `BHD_IDENTITY_ISSUER`، `BHD_OAUTH_CLIENT_ID`، `BHD_OAUTH_REDIRECT_URI` | `.env.example` ولوحة Vercel |
   | `.env` | `AWS_ACCESS_KEY_ID`، `AWS_SECRET_ACCESS_KEY`، `AWS_ENDPOINT_URL_S3`، `AWS_REGION`، `NEON_FUNCTION_BACKUP_BASE_URL` | يكتبها `neon deploy`؛ لازمة فقط لسكربتات النسخ الاحتياطي |

   **انتبه:** `.env.local` بهذا الإعداد يشير إلى **قاعدة الإنتاج** — `npm run dev` يقرأ ويكتب بيانات حقيقية. للتجارب استخدم قاعدة محلية مؤقتة (البند 6).
4. **الربط (اختياري):** `vercel link` (المشروع `bhd-hr`، الفريق `bhdom89-8158s-projects`) و`neon link` (المشروع `billowing-hat-97652194`). المجلدان `.vercel` و`.neon` في `.gitignore`.
5. **التحقق:**
   ```powershell
   npm run typecheck
   npm test
   npm run build
   ```
6. **اختبارات المتصفح على قاعدة مؤقتة:** شغّل Postgres محلياً (مثل `embedded-postgres` في مجلد مؤقت خارج المستودع)، اضبط `DATABASE_URL` و`DATABASE_URL_UNPOOLED` عليها في الجلسة، ثم `npx prisma db push --skip-generate` و`npm run e2e:seed` و`npm run build` و`npx next start -p 3100` و`$env:PW_CHANNEL="msedge"; npx playwright test`. احذف القاعدة والمجلد بعدها.
7. **الدخول المحلي:** `http://localhost:3000/login?local=1` (اسم المستخدم وكلمة المرور)؛ زر BHD يذهب إلى `id.bhd-om.com` الحقيقي.
8. **النشر:** فقط `git push origin main` (Vercel ينشر تلقائياً). لا `vercel deploy` يدوي.

## 5. قواعد العمل المتّبعة (للاستمرار عليها)

- **الأسرار:** لا يُرفع إلى GitHub أي ملف `.env` أو قاعدة أو نسخة احتياطية أو مستند مرفوع. لا تُطبع كلمات المرور أو روابط الاتصال الكاملة. قبل كل commit فحص الأسرار في الفرق ويجب أن يعطي 0:
  ```powershell
  git add -A; (git diff --cached | Select-String -Pattern 'postgres(ql)?://|npg_|AUTH_SECRET=|VERCEL_OIDC_TOKEN=|eyJhbGci|BACKUP_KEY=' | Measure-Object).Count
  ```
- **الإنتاج:** نسخة احتياطية (أو تسجيل توقيت UTC للاسترجاع من سجل Neon) قبل أي `db push`، و`prisma migrate diff` قبله وبعده. لا SQL مدمّر إلا على قواعد مؤقتة. فروع `production` و`backup-before-*` واللقطات يحذفها المالك فقط. فحوص الإنتاج بلا جلسة.
- **التجارب المحلية:** قاعدة Postgres مؤقتة جديدة ببيانات وهمية، تُحذف مع الخوادم والملفات المؤقتة بعد الانتهاء. لا تُتجاوز حماية Prisma من الأوامر الخطرة.
- **الواجهة:** العربية أولاً (`t(ar, en)`)، ألوان BHD (`#092d24`، `#075c45`)، لا تمرير أفقي على 360px، دعم الوضع الليلي، بلا `window.confirm` (خاصية `confirm` في `SubmitButton`).
- **الجلسة (`BHD-SESSION-POLICY.md`):** لا `router.refresh()` عند التركيز أو الظهور، لا keepalive، لا `Set-Cookie` على القراءة.
- **بعد كل تغيير:** `tsc` والوحدة والبناء وPlaywright، ثم التوثيق (سجل النشر §جديد، التقني، دليل المستخدم، مركز المساعدة `src/lib/help.ts`)، ثم الدفع وفحص Vercel وCI والإنتاج.
