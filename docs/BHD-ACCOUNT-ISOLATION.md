# عزل بيانات الحساب بعد التبديل (خصوصية — نموذج جوجل)

> **الحالة:** إلزامي لكل منتج مرتبط بـ `id.bhd-om.com`.  
> **تاريخ التحليل:** 29 أكتوبر 2026 — عطل مؤكد على [BHD-HR](https://github.com/ainoamn/BHD-HR).  
> **لوحة الربط:** https://id.bhd-om.com/admin#connect  
> **النموذج:** مثل جوجل `authuser` — كل تبويب مربوط بحساب عبر `?au=<sub>`.

---

## العَرَض

يتغيّر الحساب في قائمة التبديل، لكن تحية الصفحة / الأرقام / المنشأة تبقى للحساب السابق، أو تبويبان لنفس المنتج يتزامنان عند التبديل.

---

## السبب الجذري

1. تبديل Bearer بدون إعادة كتابة كوكي المنتج (`hr_session`).
2. كوكي المنتج مشترك بين التبويبات → تبويب يسرق جلسة الآخر.
3. غياب ربط URL بالحساب (مثل `authuser`) → لا عزل حقيقي بين النوافذ.

---

## القاعدة (نموذج جوجل)

### ربط التبويب (`?au=<sub>`)
1. بعد التبديل: `?au=<bhdSub>&_bhd=<ts>` مرة واحدة ثم يُزال `_bhd` بهدوء (`history.replaceState`).
2. `sessionStorage`: خريطة `bhd_account_tokens[sub]` + `bhd_active_au`.
3. عند التطابق: لا ملاحظة ولا حجاب — الصفحة تعمل مباشرة.
4. عند الانحراف (تبويب آخر): `POST /api/auth/bhd/rebind` بصيغة JSON صامتة بلا شاشة ولا نص.

### التبديل (فقط عند اختيار حساب)
1. غطاء فارغ بلا نص (لا «جاري عزل…»).
2. `POST /api/auth/switch` مع `X-BHD-Persist-Cookie: 1`.
3. ثم form `rebind` لإعادة تحميل كاملة (عزل React state 100%).
4. الرأس = إيميل جلسة المنتج فقط.

### نوافذ متعددة
كوكي المنتج مشترك. `BhdSilentSso` يصلح بهدوء كل ~20ث أو عند الظهور — بلا وميض وبلا ملاحظات.

### على المنتجات
1. تبديل صريح → hard rebind. انحراف خلفي → silent JSON rebind.
2. ممنوع `/start` دون handoff بعد التبديل.
3. امسح كوكي المنشأة مع إعادة الجلسة.
4. لا تُظهر أي رسالة عزل للمستخدم.

تفاصيل الأمر للوكيل: [`BHD-CURSOR-PRODUCT-WIRE.md`](BHD-CURSOR-PRODUCT-WIRE.md) §3.

مرجع التطبيق: `src/lib/identity/client.ts` + `BhdPrivacyGate` + `BhdSilentSso`.

---

## تحقق

1. حسابان → بدّل → الحجاب → الرابط فيه `au=` → التحية والإيميل والمنشأة للحساب الجديد فقط.
2. تبويبان بروابط `au` مختلفة → تبديل أحدهما لا يخلط بيانات الآخر (بعد إعادة الربط الصامت).
3. فتح تطبيق BHD آخر من المبدّل يتبع الحساب النشط (كوكي الهوية محدّث).
