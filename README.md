## المزايا

- **الموظفون:** ملف كامل، ترجمة فورية للاسم بالذكاء الاصطناعي، كل جنسيات العالم بالعربية والإنجليزية (العماني افتراضياً) مع بحث، وثائق بتواريخ انتهاء ومرفقاتها، رقم تلقائي، ربط بكفيل.
- **إعدادات الموارد البشرية:** مسميات وظيفية وأقسام جاهزة باللغتين قابلة للإضافة والتعديل، أنواع إجازات بعدد أيامها والوظائف المشمولة، وعلاوات (مبلغ ثابت أو نسبة، شهرية أو ربعية أو نصف سنوية أو سنوية)، مع ترجمة الأسماء بالذكاء الاصطناعي.
- **دفتر العناوين:** كفلاء (شركات وأفراد) بعرض بطاقات / قائمة / جهات اتصال، وطباعة جهات الاتصال للكل أو لكفيل معيّن.
- **الحضور والإجازات:** تسجيل بالفترة، رصيد لكل نوع إجازة تعرّفه المنشأة، وتنبيه أحمر عند التجاوز أو قرب النفاد.
- **الرواتب:** إنشاء مسير الشهر، خصم الغياب تلقائياً، صرف فردي أو جماعي، قسيمة وإيصال وكشف مسير ثنائية اللغة.
- **التقويم والتنبيهات:** استحقاق الرواتب، انتهاء المستندات، أعياد الميلاد، الإجازات، تذكيرات متكررة.
- **طلبات الموظفين والخطابات الموقّعة:** الموظف يطلب من بوابته شهادة راتب أو بيانات أو خبرة أو رسالة تحويل راتب أو عدم ممانعة أو سلفة أو استقالة، والإدارة تعتمد إلكترونياً فيصدر الخطاب جاهزاً بتوقيع المنشأة وختمها ورمز QR يفتح صفحة تحقق عامة («مستند أصلي معتمد») مع تحميل الأصل.
- **التقارير وسجل العمليات.**
- **منظومة BHD:** دخول موحّد، جلسة حتى الخروج الصريح، مشغّل التطبيقات، فوتر «برامجنا»، الهوية البصرية الرسمية.
- **المنشآت والصلاحيات:** كل حساب BHD يحصل فوراً على منشأته الخاصة، وبيانات كل منشأة معزولة عن غيرها. الوصول لمنشأة أخرى برابط دعوة من مسؤولها فقط، بصلاحية مسؤول / مدير / مستخدم (عرض فقط) أو صلاحيات مخصصة لكل قسم (عرض، إضافة، تعديل، حذف، صرف، تصدير).
- **التقارير:** طباعة وتحميل Excel وPDF.
- **السلف والمكافآت والخصومات:** مقدم راتب يُسترد بالأقساط مع إيصال استلام، ومكافآت وبدلات واستحقاقات تُضاف، وخصومات مستقبلية لمرة أو لعدة أشهر أو مستمرة؛ تُطبّق تلقائياً على رواتب الأشهر وتظهر في القسيمة.

## الموقع المنشور

**https://bhd-hr.vercel.app** — على Vercel، وقاعدة البيانات PostgreSQL على Neon. كل دفع إلى `main` في GitHub ينشر تلقائياً. الدخول بحساب BHD الموحّد بلا تفعيل يدوي: الحساب الجديد تُنشأ له منشأته ويكون مسؤولها، ولا يرى بيانات غيره إلا إذا أضافه مسؤول منشأة أخرى من الإعدادات ← أعضاء المنشأة. تفاصيل النشر في [`docs/BHD-HR-TECHNICAL.md`](docs/BHD-HR-TECHNICAL.md) §7.

## التشغيل المحلي

```bash
npm install
neon link --project-id billowing-hat-97652194 --branch production -y   # يكتب روابط القاعدة في .env.local
copy .env.example .env      # ثم عبّئ AUTH_SECRET وقيم BHD (روابط القاعدة تأتي من .env.local)
npm run dev
```

افتح http://localhost:3000. النسخة المحلية تتصل بقاعدة Neon نفسها، فالبيانات واحدة محلياً وعلى الموقع. لقاعدة جديدة فارغة شغّل `npm run db:setup` مرة واحدة.

- مع `BHD_OAUTH_CLIENT_ID=bhd-hr`: يحوّلك النظام إلى دخول BHD.
- بدونه: دخول محلي. أول تشغيل `admin@bhd.local` / `admin123`، غيّرها فوراً. كلمة المرور الافتراضية لا تعمل على النسخة المنشورة.
- دخول الطوارئ دائماً على `/login?local=1`.

## البيانات والخصوصية

- البيانات والملفات المرفوعة في مشروع Neon المستقل «BHD HR» (`billowing-hat-97652194`)، ولا شيء منها في GitHub.
- `.env` لا يُرفع إلى GitHub ولا إلى Vercel (`.gitignore` و`.vercelignore`)؛ `.env.example` يوضح أسماء المتغيرات فقط.
- نسخ SQLite القديمة (`prisma/*.db`) باقية على الجهاز للرجوع فقط، ومستثناة من Git.
