# BHD-HR — نظام الموظفين والرواتب

نظام ثنائي اللغة (عربي / إنجليزي) لشركة بن حمود للتطوير لإدارة بيانات الموظفين والكفلاء، والحضور والإجازات، والمستندات وتواريخ انتهائها، وصرف الرواتب مع قسيمة وإيصال قابلين للطباعة، وتقويم وتنبيهات. يدخل المستخدمون بحساب BHD الموحّد عبر `https://id.bhd-om.com`.

## المزايا

- **الموظفون:** ملف كامل، وثائق بتواريخ انتهاء، رقم تلقائي، ربط بكفيل.
- **دفتر العناوين:** كفلاء (شركات وأفراد) بعرض بطاقات / قائمة / جهات اتصال، وطباعة جهات الاتصال للكل أو لكفيل معيّن.
- **الحضور والإجازات:** تسجيل بالفترة، أرصدة سنوية / مرضية / تعويضية / أخرى، وتنبيه أحمر عند التجاوز أو قرب النفاد.
- **الرواتب:** إنشاء مسير الشهر، خصم الغياب تلقائياً، صرف فردي أو جماعي، قسيمة وإيصال وكشف مسير ثنائية اللغة.
- **التقويم والتنبيهات:** استحقاق الرواتب، انتهاء المستندات، أعياد الميلاد، الإجازات، تذكيرات متكررة.
- **التقارير وسجل العمليات.**
- **منظومة BHD:** دخول موحّد، جلسة حتى الخروج الصريح، مشغّل التطبيقات، فوتر «برامجنا»، الهوية البصرية الرسمية.
- **الصلاحيات:** مسؤول / عرض فقط / بانتظار التفعيل.

## الموقع المنشور

**https://bhd-hr.vercel.app** — على Vercel، وقاعدة البيانات PostgreSQL على Neon. كل دفع إلى `main` في GitHub ينشر تلقائياً. الدخول بحساب BHD الموحّد؛ أول مسؤول هو البريد المحدد في `BHD_ADMIN_EMAILS`، وأي حساب جديد آخر يبدأ «بانتظار التفعيل» حتى يفعّله المسؤول من الإعدادات ← المستخدمون. تفاصيل النشر في [`docs/BHD-HR-TECHNICAL.md`](docs/BHD-HR-TECHNICAL.md) §7.

## التشغيل المحلي

```bash
npm install
copy .env.example .env      # ثم عبّئ رابطي Neon و AUTH_SECRET وقيم BHD
npm run dev
```

افتح http://localhost:3000. النسخة المحلية تتصل بقاعدة Neon نفسها، فالبيانات واحدة محلياً وعلى الموقع. لقاعدة جديدة فارغة شغّل `npm run db:setup` مرة واحدة.

- مع `BHD_OAUTH_CLIENT_ID=bhd-hr`: يحوّلك النظام إلى دخول BHD.
- بدونه: دخول محلي. أول تشغيل `admin@bhd.local` / `admin123`، غيّرها فوراً. كلمة المرور الافتراضية لا تعمل على النسخة المنشورة.
- دخول الطوارئ دائماً على `/login?local=1`.

## البيانات والخصوصية

- البيانات والملفات المرفوعة في قاعدة Neon (`bhd_hr`)، ولا شيء منها في GitHub.
- `.env` لا يُرفع إلى GitHub ولا إلى Vercel (`.gitignore` و`.vercelignore`)؛ `.env.example` يوضح أسماء المتغيرات فقط.
- نسخ SQLite القديمة (`prisma/*.db`) باقية على الجهاز للرجوع فقط، ومستثناة من Git.
