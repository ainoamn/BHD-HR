# نظام الموظفين والرواتب

نظام صغير لإدارة بيانات العمال، الغياب، المستندات، وصرف الرواتب مع إيصال قابل للطباعة والتوقيع.

## التشغيل

```bash
npm install
npm run db:setup
npm run dev
```

ثم افتح http://localhost:3000

الدخول الأول:

- البريد: `admin@bhd.local`
- كلمة المرور: `admin123`

غيّر كلمة المرور واسم المنشأة من صفحة الإعدادات. الاسم والعملة والشعار يظهرون في إيصال الراتب.

## دورة العمل

1. أضف الموظف ببياناته: البطاقة، الجواز، الإقامة، والراتب.
2. سجّل الغياب أو الإجازة عند حدوثه.
3. من صفحة الرواتب اختر الشهر ثم «إنشاء رواتب الشهر».
4. افتح الراتب، راجع الخصم، ثم «تأكيد صرف الراتب».
5. اطبع الإيصال أو احفظه PDF من نافذة الطباعة (Microsoft Print to PDF) ليوقّع العامل.

راتب كل شهر يُحفظ وحده. تغيير راتب الموظف لاحقاً لا يغيّر الشهور السابقة.

خصم الغياب = (إجمالي الراتب ÷ أيام الحساب، افتراضياً 30) × أيام الغياب. نصف اليوم يُحسب 0.5. الإجازة والمرضي والمهمة الرسمية لا تُخصم تلقائياً.

## الدخول الموحّد BHD

- انسخ `.env.example` إلى `.env` وعبّئ القيم. بدون `BHD_OAUTH_CLIENT_ID` يبقى الدخول المحلي بكلمة المرور.
- بعد تسجيل العميل `bhd-hr` في ONE-BHD وضع قيمه، تصبح `/login` غلافاً يحوّل إلى `https://id.bhd-om.com`، ودخول الطوارئ على `/login?local=1`.
- التفاصيل وقالب 12.8 المعبّأ: [`docs/BHD-HR-SSO-INSTALL.md`](docs/BHD-HR-SSO-INSTALL.md). المرجع: باقي ملفات `docs/`.

## البيانات

قاعدة البيانات ملف محلي: `prisma/dev.db`. صور المستندات في `storage/uploads`. لا تفتح النظام على جهازين في الوقت نفسه حتى لا يتلف ملف قاعدة البيانات أثناء مزامنة Dropbox.
